# Huntington Disease Risk Classifier

A machine learning model to classify and predict the risk of Huntington's Disease based on clinical/genetic features.

## Overview

This project builds a classification model to assess the risk level of Huntington's Disease. It uses supervised learning techniques to analyze relevant features and predict outcomes.

## Files

- `model.ipynb` — Main Jupyter Notebook containing data preprocessing, model training, evaluation, and results

## Requirements

- Python 3.x
- Jupyter Notebook
- pandas
- numpy
- scikit-learn
- matplotlib / seaborn

## How to Run

1. Clone the repository:
   git clone https://github.com/mehakgupta-13/huntington-disease-risk-classifier.git

2. Open the notebook:
   jupyter notebook model.ipynb

3. Run all cells sequentially
